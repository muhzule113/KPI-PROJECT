# Penilaian KPI harian dilakukan Supervisor

Status: digantikan oleh [ADR 0004](0004-workflow-platform-dan-publikasi.md) pada 7 September 2026. Keputusan lama berikut disimpan sebagai histori.

Absensi tim dan fakta KPI harian dicatat oleh Supervisor dari daftar anggota pada snapshot assignment, lalu sistem otomatis meneruskan entri siap review tanpa Submit Harian karyawan. Keputusan ini mengurangi duplikasi input dan menjaga satu pemilik fakta operasional per cabang; karyawan tetap hanya melihat status dan hasil KPI.
